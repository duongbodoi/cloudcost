# CLI `cost-guardian.py`

Giai đoạn 3 – hạng mục 30 (cấu hình, Ngô Xuân Hậu) và 31 (triển khai, Nguyễn Tùng Dương).

- `python cost-guardian.py deploy`  – hỏi đáp, sinh `terraform/main/tfvars.json`, chạy `terraform init/apply`.
- `python cost-guardian.py destroy` – chạy `terraform destroy`.

Danh sách câu hỏi và tên biến: mục 7 CONVENTIONS (phần Budget còn ⏳ chưa chốt).
